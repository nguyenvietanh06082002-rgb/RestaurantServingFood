# `assets/images/` — Hình ảnh

## Đặt ở đây
- Logo, banner, ảnh minh hoạ, ảnh empty-state, background.

## Không đặt ở đây
- Icon nhỏ dạng glyph → `assets/icons/`.
- Ảnh do người dùng upload → lưu ở server/CDN, không commit.

## Quy ước
- Tên `kebab-case`, có thể nhóm theo màn hình: `auth/login-bg.webp`.
- Nén ảnh trước khi commit; ưu tiên `.webp`.
