# `features/settings/` — Cài đặt

Tuỳ chỉnh của người dùng / ứng dụng: giao diện, ngôn ngữ, thông báo, bảo mật.

## Ví dụ nội dung
- `components/`: `ThemeSettings`, `LanguageSettings`, `NotificationSettings`
- `hooks/`: `useSettings`
- `slice.js`: `theme`, `language`
- `constants.js`: danh sách theme, ngôn ngữ hỗ trợ

Tổ chức theo cấu trúc chuẩn trong `features/README.md`.
